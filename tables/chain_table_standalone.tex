\captionof{table}{Posterior median of $\gamma$ in each of four independent MCMC chains, when the public code of Saad \& Ting (2026) is fitted to the 36 observed pairs and only the error $\sigma_{r_\perp}$ of the projected-separation likelihood (their Eq.~13) is changed. The original code sets $\sigma_{r_\perp}=\max(0.05\,r_\perp,\sigma_d)$, where $\sigma_d$ is the error of the distance, so the median $\sigma_{r_\perp}/r_\perp$ is 188\%. A fit is counted as converged when the four chains agree, i.e.\ $\hat{R}\le 1.03$ and the effective sample size is at least 100. The effective sample size (ESS) is the number of independent draws that the correlated MCMC draws are worth: the converged fits have ESS $=233$--849 out of 12\,000 draws. Fits shown in grey do not meet this criterion ($\hat{R}=1.06$--1.77, ESS $=6$--92). All other settings follow the original code (3000 draws and 2000 tuning steps per chain, target acceptance 0.98, seed 123, nutpie sampler).}
